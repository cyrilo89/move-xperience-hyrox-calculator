# Contribuer

Les corrections et améliorations sont bienvenues.

Pour signaler un problème, ouvre une issue avec les valeurs saisies, le résultat obtenu, le résultat attendu et le navigateur utilisé. Ne joins pas de données personnelles.

Pour proposer un changement, crée un fork et une branche, puis une pull request décrivant son utilité. Garde l’outil simple, accessible, utilisable hors ligne et sans collecte de données. Pour un changement des calculs, mets à jour `calculator.js`, son bloc intégré dans `index.html`, puis lance `node test.js`. Vérifie aussi le résultat dans un navigateur sur une largeur mobile et desktop.

Améliorations possibles : traduction, saisie d’allures différentes par kilomètre, répartition plus détaillée de la Roxzone. Ce sont des pistes, pas des fonctionnalités déjà disponibles.
